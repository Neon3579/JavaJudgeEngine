06 · NON-TRIVIAL RULES

구현 시 비자명 규칙

위반 시 정확성·스레드 안전이 깨진다. 구현 전 반드시 숙지.

// RULE 01

전역 스트림 직렬화

System.in/out은 JVM 전역. JavaJarSolution이 스트림 교체 → Java 풀이 병렬 시 출력 섞임. 교체 구간을 static 락으로 직렬화. 병렬성은 외부 프로세스에서 확보.

// RULE 02

타임아웃 전략

외부 프로세스: waitFor(timeout) + destroyForcibly() 확실 종료. Java 풀이: 같은 JVM이라 강제 종료 불가 → 데몬 스레드 + Future.get(timeout) best-effort.

// RULE 03

예외 격리 (NFR-04)

GradingTask.call()은 케이스 단위로 예외를 잡아 errorMessage에 기록하고 계속 진행. 풀이 1개 크래시가 전체 벤치마크를 깨선 안 됨.

// RULE 04

불변 + 방어적 복사

모든 도메인/데이터 객체는 생성자 주입 + getter, 컬렉션은 List.copyOf. 공유 가변 상태 0 (NFR-05). 로깅은 메인 스레드 순차.

// RULE 05

메모리 제한 = 메타데이터

memoryLimit는 보관만, 강제하지 않는다. Problem의 메타 필드로 저장.

// VERIFY

검증 = Main 데모 러너

JUnit 없음. 단일 "테스트" = 단일 풀이를 단일 문제로 실행. E2E end-to-end 실행으로 검증. 결과는 ai_rec.md에 기록.
